# CC-Gui 界面层级与视觉规格（clean-room）

本文档只记录通过公开截图和运行界面观察得到的界面事实，用于从零实现 Codex CLI 的 JetBrains 上层界面。实现不得复制 CC-Gui 的 React、CSS、图标资源或业务代码，也不得带入其供应商抽象和增强提示词。

## 1. 总体结构

工具窗口是单列纵向工作区，不使用常驻侧栏或三栏分割：

```text
JetBrains 工具窗标签栏（由 IDE 管理）
└─ Codex GUI WebView
   ├─ 会话页
   │  ├─ 顶部会话栏（固定，50px）
   │  ├─ 消息壳（唯一伸缩并滚动的区域）
   │  │  ├─ 左侧消息锚点轨道（宽20px，面板≤400px隐藏）
   │  │  └─ 消息列表
   │  ├─ 滚动到底按钮（需要时悬浮）
   │  ├─ 状态面板（修改/任务；默认折叠）
   │  └─ 输入区（固定在底部）
   │     └─ 输入卡
   │        ├─ 上下文/附件行
   │        ├─ 多行输入
   │        └─ 底部工具栏
   ├─ 历史页（替换会话页主体，不是左侧栏）
   └─ 设置页（替换会话页主体，内部为设置侧栏 + 内容区）
```

## 2. 会话页层级

### 顶部会话栏

- 高度最小 50px；内边距上/右/下/左为 `8/8/8/16px`。
- 左侧是单行省略的会话标题，14px、600 字重；悬停才出现编辑按钮。
- 右侧是 32×32px 无底色图标按钮，顺序为：新会话、搜索、历史、设置。
- 背景使用次级栏颜色，底部 1px 分隔线。
- 不显示供应商名称、供应商切换或自定义品牌导航。

### 消息区

- 消息容器占满顶部栏和底部控件之间的剩余空间，只允许纵向滚动。
- 单条消息默认内边距 `16px 20px`、内容间距 `6px`，条目之间使用极弱的 1px 分隔线。
- 用户消息右对齐；蓝色气泡，内边距 `10px 14px`，圆角 `12px 12px 2px 12px`，最大宽度 85%。
- Codex 文本左对齐且无外层气泡；普通文本与 Markdown 直接落在页面背景上。
- 推理、命令、MCP、计划和文件操作只在各自内容内部使用弱底色卡片，不把整段助手输出做成聊天卡片。
- 代码块使用等宽字体、暗色块、细边框和小圆角，并在右上角提供复制操作。
- 宽度大于 400px 时显示消息锚点：左侧 4px 起、宽 20px，轨道 2px，节点 10px；消息区相应增加 26px 左内边距。

### 状态面板

- 位于消息区与输入区之间，外边距 `0 20px 8px`。
- 折叠条为整行圆角容器：1px 边框、6px 圆角、`5px 8px` 内边距。
- 本插件只保留与 Codex 原生能力匹配的两个页签：`任务` 与 `修改`。
- 修改页签必须实时显示文件数及 `+新增/-删除` 统计；点击后向上展开浮层，最大高度约 200px。
- 修改列表每行展示状态、相对路径、统计和操作；支持打开差异、接受、撤销，以及全部接受/全部撤销。
- 修改捕获来源是 Codex 回合前后工作区快照与 app-server diff 事件，不依赖 Git 是否追踪该文件。

### 输入区

- 外层内边距 `9px 8px 8px`，与消息区之间有 1px 弱分隔。
- 输入卡为单个连续容器：1px 边框、8px 圆角、页面同色背景。
- 悬停和 `focus-within` 时边框变蓝，并增加 1px 同色外描边。
- 上下文行最小 32px，`6px 12px` 内边距；文件/图片/Skill 以紧凑标签出现。
- 输入正文内边距 `6px 8px`，字体 14px、行高 1.5，默认四行高度，可扩展到 240px。
- 占位文案明确提示原生入口：`@ 引用文件，/ 使用 Codex 命令，Enter 发送`。
- 底部工具栏内边距 4px；左侧依次为聊天设置、Codex 标识、审批模式、模型、推理强度、工作区权限，右侧为附件、Skill、停止/发送。
- 所有选择器都是自绘按钮和向上浮出的选项卡，不使用浏览器原生 `select`；按钮透明背景、11px 字体、4px 圆角，菜单为 7px 圆角暗色卡片。
- 聊天设置从滑杆图标向上展开，宽约 250px；包含提示词、Agent 身份、Codex CLI 进程、流式传输和思考过程。供应商切换与 SDK/Node 依赖管理不进入本插件。
- 审批模式显示为中文：`谨慎审批 / 按需审批 / 全自动`；全自动使用橙色闪电强调。
- 发送按钮 28×28px、蓝色背景、4px 圆角。
- 不存在供应商选择器，也不提供“增强提示词”按钮。

## 3. 历史页

- 点击顶部历史图标后，历史页替换会话主体；顶部显示返回按钮和标题。
- 页面工具栏包含搜索、收藏筛选和必要的会话管理操作。
- 历史项按整行排列，不做侧边栏卡片：`16px 24px` 内边距、底部极弱分隔线。
- 标题 600 字重；右侧显示时间；第二行用 12px 弱文字显示会话元数据。
- 悬停只增加极浅背景，不改变布局。

## 4. 设置页

- 设置页替换会话主体；内部左侧为 176px 固定侧栏，右侧只有当前分类的可滚动内容，内容内边距 24px。
- 侧栏行高约 38px，图标 16px；当前项使用蓝色整行底色与左侧 3px 白色强调线。窄于 620px 时侧栏折叠为 58px 图标栏。
- 分类固定为：`基础设置 / 提示词 / Agent 身份 / MCP`。
- 基础设置包含模型、推理强度、审批、工作区权限、流式传输、思考过程、会话原生操作和账户用量。
- 提示词包含全局提示词和项目提示词；它们是用户明确配置的 Codex 原生 developer instructions，只从新会话生效，不是 CC-Gui 的隐藏增强提示词。
- Agent 身份使用列表卡片，支持新建、编辑、删除与选择；选择结果同样只作为用户配置的原生指令。
- MCP 使用服务器卡片展示名称、认证状态和工具数，支持打开 `~/.codex/config.toml` 与调用 app-server 原生重新加载。
- 控件使用 13px 字体、`8px 12px` 内边距、4px 圆角和 1px 边框。
- 不出现 Claude、Gemini、OpenCode 或任何供应商字段。

## 5. 结构化提问

- `item/tool/requestUserInput` 到达时在 WebView 内显示居中模态窗口，不使用 Swing 单行输入框。
- 标题、问题进度、短标题、问题正文、方案列表与底部操作形成明确层级。
- 每个方案是整行可点击卡片，主标题 13px、说明 11px；选中项使用蓝色边框和弱蓝背景。
- 支持“其它”自由输入、纯文本问题、敏感输入、多问题上一步/下一步，以及按问题 ID 回传答案数组。
- 不设置倒计时或五分钟自动取消；只有用户提交、取消或项目关闭才结束请求。

## 6. 暗色视觉令牌

| 用途 | 值 |
|---|---:|
| 页面/聊天背景 | `#1e1e1e` |
| 栏与弹层背景 | `#252526` |
| 三级背景 | `#2b2d31` |
| 悬停背景 | `#35373c` |
| 主文字 | `#cccccc` |
| 次文字 | `#e0e0e0` |
| 弱文字 | `#858585` |
| 占位文字 | `#666666` |
| 主边框 | `#333333` |
| 次边框 | `#3e3e42` |
| 焦点/主操作 | `#007fd4` |
| 用户气泡 | `#005fb8` |
| 新增 | `#89d185` |
| 删除/错误 | `#ff6b6b` |

字体优先使用 JetBrains IDE 注入的 UI 字体；代码使用 IDE 编辑器字体。正文基准 13px，输入 14px，工具栏/元数据 11–12px。

## 7. 响应式规则

- 窄工具窗仍保持单列，绝不自动退化成多栏或水平分割。
- ≤400px 隐藏消息锚点；标题和选择器文字允许省略，图标操作保留。
- 工具栏空间不足时先折叠选择器文字，不能挤压发送/停止按钮。
- 历史、设置、修改详情均在当前列内显示；修改详情向上浮出，避免占用输入区高度。

## 8. Codex 原生约束

- 后端固定为 `codex app-server --stdio`，模型供应商固定 OpenAI。
- 用户输入原样作为 Codex `input` 发送；只结构化传递文本、文件、图片与 Skill，不拼接 CC-Gui 上层提示词或增强提示词。用户主动保存的全局、项目和 Agent 指令通过 `developerInstructions` 传给新会话。
- `/new`、`/compact`、`/review`、`/rewind`、`/mcp`、`/usage` 是 UI 到 Codex 原生方法的快捷入口。
- 每一回合开始前建立工作区快照，回合中响应 diff/fileChange 事件重扫，回合完成后最终扫描；所有检测到的新增、修改、删除文件统一进入修改页签。
